# 酷安绿 · kuan-green

> WBOX 主题 01。默认为底，只换一档绿。

- **version** 1.0.0　**api** 1　**author** WBOX
- **engine** flat　**performance** minimal　**chrome** custom

## 设计口径

结构 100% 继承内置「默认」皮肤：行高 40 / 字号 13 / 图标 16 / 标题栏 36 / 圆角 0，
零位图、零动画、零浮层。**只改 26 个颜色 token**，所以它的开销和默认皮肤完全一致，
连一帧动画都不多。

## 配色

| | 浅色 | 深色 |
|---|---|---|
| 主色 `on` | `#0C8040` | `#34D07A` |
| 正文 `fg` | `#0A2216` | `#E7EFE9` |
| 窗口底 `glass` | `#FCFEFD` | `#0C1310` |
| 发丝线 `hair` | `#DCE9E1` | `#1B2620` |
| 悬停底 `fill_2` | `#F3F9F5` | `#121A16` |

浅色主色选 `#0C8040`：白字压它 5.03:1，它当绿字压白底 4.96:1——一个色同时胜任
「开关轨道底色」和「强调文字」，不必为文字再加第二个绿。深色主色 `#34D07A`，
把手用近黑 `#08130D`（9.42:1）。

其余中性色全部带绿调（正文 `#0A2216` 而不是纯黑），避免"绿点贴在一块灰白板上"的割裂。

## 实测对比度

按 8 位色合成后的不透明值算：

| 组合 | 浅色 | 深色 |
|---|---|---|
| 正文 / 窗口底 | 16.54 | 16.05 |
| 次级 `t2` / 窗口底 | 7.64 | 8.63 |
| 提示 `t3` / 窗口底 | 5.01 | 5.65 |
| 提示 `t3` / 悬停底 | 4.75 | 4.97 |
| 白字 / 主色 | 5.03 | — |
| 近黑字 / 主色 | — | 9.42 |

正文与次级都在 AA 以上；提示项在最不利的悬停底上仍 ≥ 4.5。

## 安装

设置 →「从文件安装皮肤…」→ 选 `kuan-green.wbskin`（或 `kuan-green.zip`，同一个包），
装完在「外观」列表里点「酷安绿」。

`.wbskin` 与 `.zip` 内容完全一致，只是后缀不同——`.wbskin` 是面板的默认筛选，
`.zip` 方便在资源管理器里直接看内容或用命令行解压。

手动装也可以：把 `skin.json` 与 `preview.png` 放进
`<安装目录>\skins\kuan-green\`（目录名必须与 id 一致）。注意解压时别多套一层——
装好的落点必须是 `skins\kuan-green\skin.json`，不能是 `skins\kuan-green\kuan-green\skin.json`。

## 卸载

外观列表里点该皮肤右侧的卸载；或删掉 `skins\kuan-green\` 目录后重开面板。
正在使用时卸载会自动回退到「默认」。
